## 题解

### 朴素解法

请允许我先简要描述一下您的算法。

对于这样的数据范围，我们可以定义一个长度为 $l + 1$ 的布尔数组，记录每棵「树」是否需要被「移走」。对于每次区间移除操作（一共 $m$ 次），把该区间内的每一棵树都标记一下（最多标记 $l + 1$ 棵树），即使重复标记也不影响结果。最后，再遍历一遍这个标记好的布尔数组，找出没有被标记的树——即被保留的树的个数。

由此，上述算法的时间复杂度是 $O(M L)$，空间复杂度为 $O(L)$。对于此题而言绰绰有余，但是您也发现了，这看起来并不像最优解。

```cpp
#include <...>
using namespace std;

int main() {
    int l, m; cin >> l >> m;
    bitset<size_t(1e4 + 9)> bl;
    for (int _ = 1, u, v; _ <= m; ++_) {
        cin >> u >> v;
        for (int i = u; i <= v; ++i)
            bl[i] = true;
    }
    int ans = 0;
    for (int i = 0; i <= l; ++i)
        ans += bl[i];
    cout << l + 1 - ans;
    return 0;
}
```

### 差分

说实话，这道题最适合的算法便是差分。差分思路简单又常用，应当也是本题时间复杂度最优的算法。不过需要注意，差分也不是万能的，它更适合离线（只在最后统一查询）、$l$ 较小的情况。

本题可以转化为：初始有一个长度为 $l + 1$、元素全为 $0$ 的数组。对于每次区间操作 $[u, v]$，考虑将该区间内的所有数自增 $1$。最后，数组中仍然为 $0$ 的元素个数即为最终答案。

而差分的算法理念便是如此：差分可以在 $O(1)$ 的时间复杂度下进行区间修改，在 $O(L)$ 的时间复杂度下进行查询。本题的时间复杂度即为 $O(M + L)$。从乘积变成加法，时间复杂度大大降低，足以应对 $m$ 极大的情况；而由于空间复杂度为 $O(L)$，它要求 $l$ 不能过大，原因便在于此。

如果您没有学过差分，非常建议您先学习「前缀和」算法，再自己推导一下「差分」算法，两者均简单易写。当然，您也可以参考我如下的简要表述和代码：

对于一个数组 ${a_i}$，考虑记录差分数组 ${s_i}$，其中 $s_i = a_i - a_{i - 1}$。也就是说，我们记录原 ${a_i}$ 数组中相邻两数之差。特别地，为了计算方便，${a_i}$ 数组是 1-indexed 的（下标从 $1$ 开始），规定 $a_0 = 0$。

如何从 ${s_i}$ 反推 $a_i$ 的值？通过拆分 $s_1, s_2, \dots$ 可知：

$$
\begin{align*}
 \sum_{x=1}^{i} s_x &= s_1 + s_2 + \dots + s_i \\
  &= (a_1 - a_0) + (a_2 - a_1) + \dots + (a_i - a_{i-1}) \\
  &= a_i - a_0 \\
  &= a_i
\end{align*}
$$

差分如何优化区间自增？显然，对于区间 $[u, v]$ 中的每个数自增 $x$，只需要把 $s_u \gets s_u + x$，且 $s_{v + 1} \gets s_{v + 1} - x$。其中前者影响了 $[a_u, +\infty)$ 的每一个值，而后者消除了前者对于 $[a_{v + 1}, +\infty)$ 的影响，故使得有且仅有 $[a_u, a_v]$ 完成了自增修改。

```cpp
#include <...>
using namespace std;

int main() {
    int l, m; cin >> l >> m;
    vector<int> s(l + 2, 0);
    for (int _ = 1, u, v; _ <= m; ++_) {
        cin >> u >> v; ++u, ++v;
        s[u] += 1, s[v + 1] -= 1;
    }
    int ans = 0;
    for (int i = 1, a = 0; i <= l + 1; ++i) {
        a += s[i];
        ans += a == 0;
    }
    cout << ans;
    return 0;
}
```

### 区间合并

上述两种算法都需要开一个长度约为 $l$ 的数组，空间复杂度为 $O(L)$。如果题目的 $l$ 巨大，比如 $l$ 最大为 $10^{18}$（仍在 C++ `long long` 数据范围内），这样的情况在算法题中很常见，而上述两种算法无论如何也无法在有限的空间限制下运行。下面介绍的区间合并（同样为离线算法）则可以很好地解决这一问题。

考虑将所有区间 $[u_j, v_j]$ 按照其左端点 ${u_j}$ 进行升序排序。维护一个当前正在合并的区间 $[L, R]$，遍历下一个区间 $[u_{j + 1}, v_{j + 1}]$：

1. 如果 $u_{j + 1} \le R + 1$，则说明区间 $[L, R]$ 和区间 $[u_{j + 1}, v_{j + 1}]$ 是可以合并的，更新 $R \gets \max(R, v_{j + 1})$。
2. 否则，这两个区间是分离的，计算新贡献的「被移走的树」的数量 $\textbf{ans} \gets \textbf{ans} + R - L + 1$，并更新 $L \gets u_{j + 1}$，$R \gets v_{j + 1}$。

该算法时间复杂度为 $O(m \log m)$，空间复杂度为 $O(m)$，勉强可以算是结合了排序和贪心的思路，但主要还是用到了离线的思想，对操作区间进行了重新排序处理。

为了体现该算法可以适应较大的 $l$ 值，以下代码中将所有存储树的位置的变量都用了 `long long` 存储。

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int main() {
    ll l; int m; cin >> l >> m;
    vector<pair<ll, ll>> d;
    d.reserve(m);
    for (int _ = 1; _ <= m; ++_) {
        ll u, v;
        cin >> u >> v;
        d.push_back({u, v});
    }
    sort(d.begin(), d.end());
    ll ans = 0;
    auto [L, R] = d.front();
    for (auto [u, v] : d) {
        if (u <= R + 1) R = max(R, v);
        else {
            ans += R - L + 1;
            L = u, R = v;
        }
    }
    ans += R - L + 1;
    cout << (l + 1) - ans;
    return 0;
}
```

### 树状数据结构

同样，树状数据结构也可以应对 $l$ 较大的情况，而其优势在于支持在线操作，能够随时修改、查询，并支持任意交替操作。本题可以用动态开点线段树或珂朵莉树实现。

鉴于两者属于数据结构中偏后的知识点，在此便不再向您展开描述这两种算法了。希望您可以在日后学习到树状数据结构时留个心，更深刻地感受它们的强大之处：在线、对数时间复杂度、灵活支持各种操作。当然，如果您想了解树状数据结构是如何实现本题的，或者想要入门学习数据结构，非常欢迎随时联系我，我很高兴为您提供更多思路。
